# Preview assets

Muscle illustrations, hero illustration, and exercise fallback are original code-native SVGs generated by `scripts/generate-preview-art.mjs`. They approximate the reference layout; they are not the screenshot application's original photographs/anatomy renders.

Exercise demonstration photographs, when present under `exercises/`, come from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), whose repository is distributed under [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md). Source exercise IDs and any substitutions are listed in `exercise-provenance.json`. Preserve this attribution/source metadata when replacing images. The preview does not reproduce complete reference screenshots as its UI.
