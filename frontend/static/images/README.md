# Preview assets

Muscle illustrations, hero illustration, and exercise fallback are original code-native SVGs generated by `scripts/generate-preview-art.mjs`. They approximate the reference layout; they are not the screenshot application's original photographs/anatomy renders.

Exercise demonstration photographs, when present under `exercises/`, come from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), whose repository is distributed under [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md). Source exercise IDs and any substitutions are listed in `exercise-provenance.json`. Preserve this attribution/source metadata when replacing images. The preview does not reproduce complete reference screenshots as its UI.

The expanded program library adds 25 demonstrations pinned to commit `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`. Existing guides are preserved. The provenance file records import batches, dataset SHA256, per-image SHA256 and pinned source URLs. `npm run test:mock` checks catalogue parity, local asset availability and these image checksums.

To reproduce one batch from the pinned `dist/exercises.json`, run `node scripts/import-exercise-assets.mjs <dataset.json> --ref=<commit SHA> --ids=<comma-separated local exercise IDs>` from `frontend`, then `npm run export:catalogue`. Scoped imports validate every mapping and fail without replacing guide metadata if an image is unavailable. See [the program-library plan](../../../PROGRAM_LIBRARY_PLAN.md) for routine sources and adaptations.
